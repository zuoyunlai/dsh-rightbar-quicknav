# dsh-rightbar-quicknav

[![DeepSeek Harness](https://img.shields.io/badge/DeepSeek%20Harness-plugin-4c78ff)](https://github.com/deepseek-ai/deepseek-harness)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**DeepSeek Harness (DSH) के दाईं साइडबार के लिए त्वरित नेविगेशन — एक खड़ी आइकन-रेल, जिससे किसी भी दाएँ टैब पर सीधे पहुँचा जा सकता है।**

> [English](README.md) · [简体中文](README-zh.md) · [日本語](README-ja.md) · [Español](README-es.md) · [Português](README-pt.md) · हिन्दी

## यह क्या हल करता है

DSH दाईं साइडबार की हर सुविधा (फ़ाइलें, Git, कार्य, टर्मिनल, ब्राउज़र, इमेज स्टूडियो, मेमोरी…) को टैब-स्ट्रिप में रखता है — पहले साइडबार खोलो, फिर टैब ढूँढो। यह प्लगइन *दाईं साइडबार खोलने* वाले बटन के ठीक नीचे एक **स्थायी आइकन-रेल** जोड़ता है:

- **सिकुड़ी हुई अवस्था में केवल 3 आइकन** — सामान्य काम में ध्यान नहीं खींचती।
- **माउस ले जाने पर** नीचे की ओर खुलती है और सभी उपलब्ध टैब दिखाती है।
- **किसी आइकन पर माउस ले जाने पर** उसका शीर्षक एक छोटे बुलबुले में दिखता है।
- **क्लिक करने पर** दायाँ साइडबार सीधे उसी टैब पर खुलता है — तीन कदम की जगह एक क्लिक।

सूची हार्डकोड नहीं है: यह होस्ट की अपनी टैब रजिस्ट्री (`sidebarRightTabs.guide()`) से पढ़ी जाती है, इसलिए **जो भी प्लगइन टैब पंजीकृत करता है, वह अपने आप रेल में आ जाता है**।

## इंस्टॉल

### प्लगइन मैनेजर से (अनुशंसित)

`प्लगइन → जोड़ें` और इस पैकेज (npm tarball या स्थानीय फ़ोल्डर) की ओर इंगित करें। बंडल पैच क्लाइंट भाग को Web / Desktop प्रोफ़ाइल में जोड़ देता है।

### मैनुअल

```bash
cd ~/.dsh/profiles/<आपकी-प्रोफ़ाइल>
pnpm add dsh-rightbar-quicknav
```

फिर **DSH को पूरी तरह पुनः आरंभ करें** — क्लाइंट मॉड्यूल बूट के समय बनते हैं, केवल पेज रीफ़्रेश पर्याप्त नहीं है।

## आवश्यकताएँ

- DSH `>= 0.2.1-rc.1` (`sidebarRightTabs` / `sidebarRight` क्लाइंट सेवाएँ चाहिए)
- React होस्ट देता है — **कोई रनटाइम निर्भरता नहीं**, **कोई बिल्ड चरण नहीं**

## व्यवहार का विवरण

| | |
|---|---|
| स्थान | व्यूपोर्ट के दाएँ किनारे से `10px`; होस्ट बटन से `50px` नीचे |
| सिकुड़ी अवस्था | 3 आइकन |
| खुलना | माउस ले जाने पर (हटने के 200ms बाद सिकुड़ती है) |
| बुलबुला | एक पंक्ति, चौड़ाई सामग्री के अनुसार; जगह न हो तो दूसरी ओर पलट जाता है |
| जंप | `sidebarRight.openTab(kind)` |
| कब छिपी | दायाँ साइडबार पहले से खुला हो, या स्क्रीन पर कोई सत्र न हो |

## डिज़ाइन सीमाएँ

- केवल additive `shell.overlay` स्लॉट में माउंट होती है — आधिकारिक UI को न ढकती है न बदलती है।
- सारा दृश्य **इनलाइन React शैलियों** में: होस्ट कोई `styles` सेवा नहीं देता, इसलिए क्लास-आधारित CSS चुपचाप बेअसर रहेगा।
- ज्यामिति **इवेंट-चालित** है (`MutationObserver` + `ResizeObserver`) — स्थिर अवस्था में शून्य पोलिंग, शून्य forced layout।
- एंकर होस्ट का ही बटन है, स्थिर एट्रिब्यूट `data-sidebar-right-expand` से मिलता है, और `aria-label` पर फ़ॉलबैक है; दोनों न मिलें तो डिफ़ॉल्ट स्थान पर आ जाती है और एक चेतावनी लॉग करती है — गायब या गलत जगह नहीं।
- कीबोर्ड सुलभ: `toolbar` + roving tabindex + तीर कुंजियाँ, `Esc` से बुलबुला बंद, फ़ोकस रूपरेखा केवल कीबोर्ड पर।
- `prefers-reduced-motion` का सम्मान; रेंडर के समय की त्रुटि ErrorBoundary पकड़ लेता है, पूरा स्लॉट सफ़ेद नहीं होता।
- UI पाठ चीनी/अंग्रेज़ी द्विभाषी; होस्ट locale सेवा दे तो `rightbarQuicknav` नेमस्पेस में पंजीकृत।

## विकास

```bash
node --check client.js     # सिंटैक्स जाँच
node --test tests/         # रेंडर स्मोक टेस्ट (कोई निर्भरता नहीं)
```

स्मोक टेस्ट असली `client.js` लोड करता है और न्यूनतम React स्टब के साथ प्लगइन के अपने `apply() → slots.inject → slots.register` पथ को चलाता है, यह जाँचते हुए कि रेंडर और effect अपवाद नहीं फेंकते। यह इसलिए है क्योंकि एक बार effect में एक अपरिभाषित पहचानकर्ता ने पूरी रेल को चुपचाप गायब कर दिया था।
